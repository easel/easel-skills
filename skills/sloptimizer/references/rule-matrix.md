# Sloptimizer Rule Matrix

Each phrase should have one Vale owner. When a phrase can be both an AI-writing
tell and an unsupported claim, choose the rule that gives the most actionable
message and do not duplicate it in another file.

| Pattern group | Current owner | Final owner | Profile | Level | Rationale |
|---|---|---|---|---|---|
| Phrase-level AI slop such as `unlock value`, `transform the way`, `pivotal moment`, `delve into` | `AISlop.yml` | `AISlop.yml` | yes | warning | High-confidence marketing/filler phrases only. Structural tells (`highlighting the…`, colon reveals) stay editorial to avoid UI/docs false positives. |
| Unsupported quality claims such as `robust`, `scalable`, `production-ready`, `seamless experience`, `powerful automation` | `UnsupportedClaim.yml` | `UnsupportedClaim.yml` | yes | warning | The fix is evidence or deletion, not synonym replacement. |
| Capability verbs such as `supports`, `provides`, `enables` | `MissingActorAction.yml` | `MissingActorAction.yml` | yes | warning | The fix is naming the actor and concrete operation. |
| Filler transitions such as `in conclusion`, `moreover`, `at its core`, `let's dive in` | `FillerTransition.yml` | `FillerTransition.yml` | yes | suggestion | These usually carry structure poorly but can be intentional. |
| Reader-steering and throat-clearing such as `worth noting`, `here's the thing`, `I hope this helps.`, and the noun-phrase frame `a parameter worth varying` | `ReaderSteeringPhrases.yml` | `ReaderSteeringPhrases.yml` | yes | suggestion | Chatbot residue uses punctuated forms (`great question!`) so ordinary English is not matched. The `worth + verb-ing` frame is bounded to evaluative gerunds (`noting`, `varying`, `unpacking`), so `a book worth reading` does not match. |
| Mannered prose such as `earns its keep`, `a dial worth turning`, `does the heavy lifting`, `under the hood`, `moves the needle` | `ManneredProse.yml` | `ManneredProse.yml` | yes | suggestion | Stock metaphors standing in for a plain statement. Phrase list only; a fresh metaphor the writer chose is editorial (`ai-writing.md`, `density-voice.md`). `headline-audit.py` reads this file's `tokens` so titles get the same list without a second owner. |
| Token-cost phrases such as `in order to`, `due to the fact that` | `TokenCost.yml` | `TokenCost.yml` | yes | suggestion | Deterministic substitutions with low semantic risk. |
| Generic adverbs such as `simply`, `quickly`, `effectively` | `Vocabulary.yml` | `Vocabulary.yml` | yes | suggestion | Prefer specifics, but context can justify them. |
| Structural patterns (colon reveals, synonym cycling, dramatic fragments, fake-profound kickers) | `references/ai-writing.md` | `references/ai-writing.md` + `references/eval.md` | editorial | n/a | High false-positive risk for Vale; editorial detect/rewrite + eval checklist. |
| Punctuated throat-clearing / chatbot chrome (`the truth is,`, `Great question!`) | `raw-profile-audit.py` | `raw-profile-audit.py` | default, results, strict | suggestion | Vale existence cannot match trailing punctuation tokens reliably. |
| Repeated sentence openings | `raw-profile-audit.py` | `raw-profile-audit.py` | default, results, strict | suggestion | Heuristic rhythm check; use as review signal, not proof. |
| Comparative hype verbs such as `beats`, `dominates`, `crushes` | `SloptimizerResults/ComparativeHype.yml` | `SloptimizerResults/ComparativeHype.yml` | results, strict | suggestion | The fix is scoping the comparison to metric, dataset, run, or time window. |
| Em dashes | `raw-profile-audit.py` | `raw-profile-audit.py` | strict | suggestion | Source-level house-style check; default prose audit does not enforce it. |
| Bold inline header bullets | `raw-profile-audit.py` | `raw-profile-audit.py` | strict | suggestion | Source-level Markdown structure check; default prose audit does not enforce it. |
| Comma-and clause chains such as `X is the table, and its form is the same` | `raw-profile-audit.py` | `raw-profile-audit.py` | strict | suggestion | Two independent clauses joined by `, and <pronoun> <verb>`; strict only because ordinary compound sentences also match. |
| Framing openers such as `With the boundary placed,` | `FillerTransition.yml` | `FillerTransition.yml` | yes | suggestion | Backward-pointing participial opener; requires a completion participle (`placed`, `settled`, `done`) so `with the config file` does not match. |
| Negation reversal such as `it is not X, it is Y` or `It is not X. It is Y.` | `raw-profile-audit.py` | `raw-profile-audit.py` | strict | suggestion | High false-positive risk, so it is available only in the explicit strict profile. Matches across a comma, semicolon, or sentence boundary on one line. |
| Meta-narration such as `this post argues`, `the argument here is` | `MetaNarration.yml` | `MetaNarration.yml` | yes | suggestion | The document narrating itself. Documentation verbs (`this section describes`) are excluded to avoid false positives in reference docs. |
| Count previews such as `four cases are common enough`, `raises two questions` | `CountPreview.yml` | `CountPreview.yml` | yes | suggestion | A sentence whose only content is the number of items that follow. A colon list naming the items does not match. |
| Formulaic headings such as `Where X breaks`, any `Why …` heading, `Two things that force Y`, `Key takeaways` | `raw-profile-audit.py` | `raw-profile-audit.py` | default, results, strict | suggestion | Heading-only check on source Markdown; Vale heading scope is not mirrored by the fixture harness. |
| Enumerated parades: consecutive paragraphs opening `The first is`, `The second is` | `raw-profile-audit.py` | `raw-profile-audit.py` | default, results, strict | suggestion | Document-level count; a single enumerated opener is fine, two or more is the tell. |
| Headline contrastive reversal such as `X, not a Y`, a trailing `is not`, `Less X, more Y` | `headline-audit.py` | `headline-audit.py` | headings in every profile; every line with `--target headline` | suggestion | Headings are excluded from the Vale pack and from the strict `NegationReversal` sentence check; a one-line headline is short enough that the reversal shapes match with low false-positive risk. |
| Headline colon list and colon reveal | `headline-audit.py` | `headline-audit.py` | same | suggestion | Editorial in prose (`ai-writing.md` colon reveals) because docs use `Label: value`; deterministic in titles, where the profile requires a claim. Clock times and ratios are exempt. |
| Headline imperative chain (three or more comma-separated imperatives) | `headline-audit.py` | `headline-audit.py` | same | suggestion | Verb-list heuristic; two imperatives joined by `and` (a two-decision ask) do not match. |
| Headline listicle count such as `Five things`, `three reasons` | `headline-audit.py` | `headline-audit.py` | same | suggestion | Generic container nouns only; `3 findings` and `two conditions` are evidence, not a listicle. Distinct from `CountPreview.yml`, which needs the sentence verb. |
| Headline stacked negation and rule-of-three triplet | `headline-audit.py` | `headline-audit.py` | same | suggestion | Two negations or an `A, B, and C` list in one title. Thousands separators (`$262,000`) do not match the list shape. |
| Headline flattery, aphorism, universal claim | `headline-audit.py` | `headline-audit.py` | same | suggestion | Phrase lists (`your best teams`, `we hold ourselves to`, `is the new`, a trailing `matters`) plus `Teams switch` / `every team` generalizations with no scope. |
| Headline mannered phrase such as `Documentation earns its keep` | `ManneredProse.yml` tokens via `headline-audit.py` | same | same | suggestion | Vale's `~heading` scope never sees a title, so the headline audit loads the Vale rule's token list at import and reports `SloptimizerHeadline.Mannered`. |
| Headline length over 10 words | `headline-audit.py` | `headline-audit.py` | same | suggestion | Hard stop; the rewrite target is 8 or fewer. `--max-words` overrides. |
| Headline inventory count | `headline-audit.py` | `headline-audit.py` | same | suggestion | A verb of possession or coverage followed by a count of plural nouns (`ships with 53 templates`, `routes twenty-one modes`). |
| Headline hedge word | `headline-audit.py` | `headline-audit.py` | same | suggestion | `also`, `just`, `simply`, `really`, `actually`, `very`, `perhaps` and kin inside a title. |
